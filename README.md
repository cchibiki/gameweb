# 同桌 Playroom

好友联机桌游网站。提供深色响应式大厅、访客昵称、房间筛选和人数排序、邀请链接、文字聊天、准备与旁观席。

## 本地运行

需要 Node.js 22.13 或更高版本。

```sh
npm ci
npm run setup:local
npm run dev
```

访问终端显示的本地地址（默认 http://localhost:5173）。不同浏览器、隐私窗口或设备是不同玩家；同一浏览器的标签页共享访客身份。刷新房间链接会恢复入房。昵称与房间数据保存在服务端 SQLite / D1，访客身份使用 HttpOnly Cookie，清除 Cookie 会建立新身份。

## 房间与游戏

- 大厅支持游戏类型、房间人数上限、等待/进行中状态、可入座条件筛选，以及人数/空位/创建时间排序。
- 房主可随时改游戏、人数和局数；修改会取消当前局、清空本组比分并重新准备。超员玩家保留在旁观席，扩大座位后按入房顺序恢复。主动旁观的玩家需自行申请入座。
- 五子棋：15 路自由五子棋，无禁手，五连或更多获胜。
- 围棋：9/13/19 路，提子、自杀禁入、全局同形限制；双方连续停一手后按盘面子空数子，白贴 7.5 目。无死子协商，请先吃净死子再数子。
- 井字棋：完整胜负、平局和交换先手。
- 谁是卧底：随机私密词语，3–6 人 1 卧底、7–12 人 2 卧底，轮流文字描述、投票和阵营胜负。
- 狼人杀：6–8 人 2 狼、9–12 人 3 狼，1 预言家、1 女巫、其余村民；完整夜间行动、药剂、查验、白天发言、投票、胜负。不含警长、猎人或语音。
- 每组 1–9 局，按胜局计分。玩家离开正在进行的对局会取消本局，不计胜负；房主离开后自动移交房主。

## 联机实现

前端 React + Vinext，后端 Cloudflare Worker + D1。房间每 1.2 秒同步，大厅每 4 秒同步。每个房间使用版本号条件更新，避免并发覆盖。服务端校验房主权限、玩家座位、轮次和动作，响应只包含该玩家有权看到的秘密。仅房间成员可读取房间详情。

本版本面向好友小规模游戏，每房最多 40 人，大厅展示最近 7 天活跃的至多 100 个房间。关闭页面不自动移出房间，缺席玩家可能阻塞回合；房主可结束本局或修改配置。尚未接入语音、用户账号恢复和大规模公网限流。

## 验证

```sh
npm test
npm run test:multiplayer
npm run typecheck
npm run build
```

联机验证需要本地服务已启动，会使用独立测试访客并清理测试房间。

## 部署

生产构建输出在 `dist/server` 与 `dist/client`。需要支持 Cloudflare Workers 的运行环境和名为 `DB` 的 D1 绑定；数据库迁移在 `drizzle/`。`.openai/hosting.json` 保留已登记的 Sites 项目身份和逻辑数据库绑定。纯静态托管不能运行此网站的联机后端。
